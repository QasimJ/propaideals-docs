# Flood risk

Check whether a UK location is inside a flood risk zone. England is answered from the Environment Agency flood map (the point is tested against each flood polygon); Scotland from SEPA flood polygons stored in PostGIS. Wales and Northern Ireland are **not covered**: `in_flood_zone` is `null` there, never `false`.

**Required scope:** `planning:read`
**Cost:** 1 request per call
**Available on:** Advanced, Professional, Business (not included in the Free plan)

## Check by coordinates

```http
GET /api/v1/flood-risk/coordinates?lat={lat}&lon={lon}
```

A point inside a SEPA polygon returns the highest-risk match. Otherwise the country of the nearest postcode decides: England gets the Environment Agency answer, Scotland outside every SEPA polygon gets `false`, and Wales, Northern Ireland or an unknown country gets `null` with `coverage: "not_covered"`.

### Request

```bash
curl "https://api.propaideals.co.uk/api/v1/flood-risk/coordinates?lat=53.4808&lon=-2.2426" \
  -H "Authorization: Bearer paid_..."
```

```python
import requests

res = requests.get(
    "https://api.propaideals.co.uk/api/v1/flood-risk/coordinates",
    params={"lat": 53.4808, "lon": -2.2426},
    headers={"Authorization": f"Bearer {API_KEY}"},
)
risk = res.json()["data"]
if risk["in_flood_zone"] is None:
    print(f"Not checked: {risk['note']}")
elif risk["in_flood_zone"]:
    print(f"At risk: zone {risk['zone_category']} ({risk['source']})")
else:
    print("Outside any mapped flood zone")
```

### Response (in zone)

```json
{
  "data": {
    "lat": 53.4808,
    "lon": -2.2426,
    "in_flood_zone": true,
    "risk_level": null,
    "zone_category": "3",
    "zone_type": null,
    "source": "ea_ogc",
    "coverage": "england_ea",
    "note": null
  }
}
```

### Response (no risk)

```json
{
  "data": {
    "lat": 53.4808,
    "lon": -2.2426,
    "in_flood_zone": false,
    "risk_level": null,
    "zone_category": "1",
    "zone_type": null,
    "source": "ea_ogc",
    "coverage": "england_ea",
    "note": null
  }
}
```

### Response (not checked)

```json
{
  "data": {
    "lat": 51.4816,
    "lon": -3.1791,
    "in_flood_zone": null,
    "risk_level": null,
    "zone_category": null,
    "zone_type": null,
    "source": null,
    "coverage": "not_covered",
    "note": "Not checked: flood zones are answered for England (Environment Agency) and Scotland (SEPA) only"
  }
}
```

The endpoint returns `200` in every case. `in_flood_zone` is tri-state: `true` (in zone 2 or 3), `false` (checked, outside every mapped zone) or `null` (not checked: read `note`). By coordinates, the country is taken from the nearest postcode centroid within 2 km; a point with no postcode that close (open moorland, remote coast, offshore) also returns `null`, since its country cannot be named.

## Check by property ID

```http
GET /api/v1/flood-risk/property/{property_id}
```

Reads the property's stored flood zone. A zone stored before the November 2026 point-in-polygon fix that is still being re-checked, or an Environment Agency answer for a home outside England, returns `null` with a `note`. With no stored zone, a Scottish home gets the SEPA polygon check and any other home returns `null`.

```bash
curl "https://api.propaideals.co.uk/api/v1/flood-risk/property/5fa1b2c3-d4e5-6f78-9012-3456789abcde" \
  -H "Authorization: Bearer paid_..."
```

Returns the same `FloodRiskResponse` shape.

## Risk levels

| Level | Zone category | Annual probability | What it means |
|---|---|---|---|
| `high` | 3a, 3b | > 1.0% (rivers/sea) | Significant flood risk — insurance premiums materially higher, lender restrictions possible |
| `medium` | 2 | 0.1–1.0% | Moderate risk — disclose on conveyancing |
| `low` | 1 | < 0.1% | Low risk |
| _(none)_ | — | — | Not in any mapped zone |

## Use cases

- **Conveyancing checks** — Pre-flag flood risk before instructing a search
- **Mortgage underwriting** — Lenders can decline or surcharge high-risk properties
- **Insurance scoring** — Quote adjustments based on flood zone overlap
- **Investor due diligence** — Filter portfolio acquisitions by flood risk
- **Refurb planning** — Avoid putting flood-vulnerable improvements in zone 3 properties

## Coverage

| Region | Coverage | Source |
|---|---|---|
| England | Flood zones 2 + 3 (rivers and sea) | Environment Agency flood map |
| Wales | Not covered (`null`) | Natural Resources Wales maps are not yet queried |
| Scotland | SEPA likelihood polygons | SEPA flood maps |
| Northern Ireland | Not covered (`null`) | No public source is queried |
